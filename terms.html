ファストカルテ利用規約

制定日：2026年10月13日

合同会社鈴木医工（以下「当社」といいます。）は、当社が提供するクラウド型電子カルテサービス「ファストカルテ」の利用条件を、以下のとおり定めます。

第1条（目的及び適用）

  1. 本規約は、本サービスの提供条件及び当社と契約者との間の権利義務関係を定めることを目的とし、本サービスの利用に関わる当社と契約者との間の一切の関係に適用されます。
  2. 当社が本サービスに関して別途定める個別規定、申込書記載の条件及び当社と契約者との間で締結する「患者データ取扱いに関する覚書」（以下「覚書」といいます。）は、本規約の一部を構成します。
  3. 本規約と個別規定又は申込書の内容が異なる場合は、個別規定又は申込書の定めが優先します。患者の個人情報の取扱いに関して本規約と覚書の内容が異なる場合は、覚書の定めが優先します。

第2条（定義）

本規約において使用する用語の意義は、次の各号に定めるとおりとします。

  1. 「本サービス」とは、当社が「ファストカルテ」の名称で提供するクラウド型の電子カルテサービス（予約取込、受付、番号札、呼び出し、待合モニター表示、診療録の記載、電子同意書、見積、会計、経営集計、練習用環境その他これらに付随する機能を含みます。）及びこれに関連して当社が提供する一切のサービスをいいます。
  2. 「契約者」とは、本規約に同意の上、当社所定の方法により本サービスの利用を申し込み、当社が承諾した医療機関の開設者をいいます。
  3. 「利用契約」とは、本規約に基づき当社と契約者との間で成立する本サービスの利用に関する契約をいいます。
  4. 「利用者」とは、契約者の役員、従業者その他契約者が本サービスの利用を認めた者で、当社所定の方法によりアカウントを付与された者をいいます。
  5. 「院」とは、契約者が開設する医療機関であって、本サービスを利用する施設単位をいいます。
  6. 「契約者データ」とは、契約者又は利用者が本サービスに入力、登録、取込又は保存した一切の情報（患者情報を含みます。）をいいます。
  7. 「患者情報」とは、契約者データのうち、患者その他の個人に関する情報をいいます。
  8. 「外部予約サービス」とは、ホットペッパービューティー、キレイパス、トリビューその他第三者が提供する予約受付サービスであって、本サービスと連携するものをいいます。
  9. 「導入費」とは、本サービスの初期設定及び導入支援の対価として契約者が支払う料金をいいます。
  10. 「月額利用料」とは、本サービスの利用の対価として契約者が毎月支払う料金をいいます。
  11. 「部分導入」とは、本サービスの機能のうち、当社と契約者が合意した一部の機能のみを利用する形態をいいます。
  12. 「練習用の院」とは、操作習熟を目的として当社が提供する、実在の患者情報を登録しないことを前提とした環境をいいます。

第3条（利用契約の成立）

  1. 本サービスの利用を希望する者は、本規約及び覚書の内容に同意の上、当社所定の申込書その他の方法により申し込むものとします。
  2. 利用契約は、前項の申込みに対し当社が承諾の通知をした時に成立します。覚書は、利用契約の成立と同時に締結されるものとします。
  3. 当社は、申込者が次の各号のいずれかに該当すると判断した場合、申込みを承諾しないことがあります。この場合、当社はその理由を開示する義務を負いません。
    1. 申込みの内容に虚偽、誤記又は記載漏れがあった場合
    2. 過去に本規約に違反し、利用契約を解除されたことがある場合
    3. 第15条に定める反社会的勢力等に該当し、又はそのおそれがある場合
    4. その他当社が承諾を不適当と判断した場合

第4条（契約内容の変更）

契約者は、利用する機能、院の数その他申込書記載の事項を変更しようとするときは、当社所定の方法により当社に申し出るものとし、当社が承諾した時に変更の効力が生じるものとします。

第5条（料金及び支払）

  1. 契約者は、当社に対し、本サービスの対価として、導入費及び月額利用料を支払うものとします。
  2. 導入費は、次の各号のとおりとします。ただし、申込書に別段の定めがある場合はその定めによります。
    1. 標準プラン：金98,000円（税別）
    2. ライトプラン：金49,800円（税別）
  3. 月額利用料の額は、申込書又は当社が別途定める料金表に定めるとおりとします。
  4. 年払いを選択した契約者の月額利用料は、12か月分の月額利用料から10パーセントを割り引いた額を一括して前払いするものとします。
  5. 既存システムからのデータ移行、院への訪問による設定・説明その他申込書に定めのない作業は、本サービスの範囲外とし、当社と契約者が別途合意した料金によります。
  6. 導入費は、利用契約の成立後、当社が発行する請求書に従い、請求書発行日から14日以内に支払うものとします。
  7. 月額利用料は、利用開始日の属する月の翌月から発生し、当月分を当月末日までに、当社が指定する方法により支払うものとします。利用開始日の属する月の月額利用料は、無償とします。
  8. 支払に要する振込手数料その他の費用は、契約者の負担とします。
  9. 契約者が料金の支払を遅延した場合、契約者は、支払期日の翌日から支払済みまで年14.6パーセントの割合による遅延損害金を支払うものとします。
  10. 当社は、受領した導入費を、理由の如何を問わず返還しません。月額利用料についても、本規約に別段の定めがある場合を除き、返還しません。
  11. 当社は、契約者に対し3か月前までに通知することにより、料金を改定することができます。

第6条（最低利用期間）

  1. 本サービスの最低利用期間は、利用開始日から起算して6か月間とします。
  2. 契約者が最低利用期間内に利用契約を解約した場合（第14条第2項により当社が利用契約を解除した場合を含みます。）、契約者は、最低利用期間の残余期間に相当する月額利用料を、解約日の属する月の末日までに一括して支払うものとします。

第7条（契約期間及び解約）

  1. 利用契約の期間は、利用開始日から最低利用期間の満了日までとし、期間満了の1か月前までにいずれの当事者からも書面又は電子メールによる別段の意思表示がないときは、同一条件で1か月間（年払いの場合は12か月間）更新されるものとし、以後も同様とします。
  2. 契約者は、解約を希望する月の末日の1か月前までに当社所定の方法により通知することにより、当該月の末日をもって利用契約を解約することができます。
  3. 年払いの契約者が契約期間の途中で解約した場合でも、当社は、既に受領した月額利用料を返還しません。

第8条（アカウントの管理）

  1. 契約者は、利用者のアカウント、パスワードその他の認証情報（以下「認証情報」といいます。）を自らの責任において管理し、利用者にも適切に管理させるものとします。
  2. 契約者は、退職その他の理由により利用者が本サービスを利用する必要がなくなった場合は、遅滞なく当該利用者のアカウントを停止又は削除するものとします。
  3. 認証情報を用いて行われた本サービスの利用は、当該認証情報に係る利用者による利用とみなし、契約者はその一切について責任を負うものとします。ただし、当社の責めに帰すべき事由による場合はこの限りではありません。
  4. 契約者は、認証情報の漏えい又は不正利用を知ったときは、直ちに当社に通知するものとします。

第9条（契約者の責任）

  1. 契約者は、患者情報の取扱いについて、個人情報の保護に関する法律（以下「個人情報保護法」といいます。）その他の法令に定める個人情報取扱事業者としての義務を自らの責任において履行するものとします。
  2. 契約者は、診療録の記載、保存、真正性の確保その他医療機関として法令上求められる義務を自らの責任において履行するものとし、本サービスの利用は契約者のこれらの義務を免除するものではありません。
  3. 本サービスは、診療録の記載及び保存を支援するものであり、診断、治療その他の医学的判断を行うものではありません。本サービスに表示される情報に基づく医学的判断は、契約者及び利用者の責任において行うものとします。
  4. 契約者は、外部予約サービスとの連携機能を利用する場合、当該外部予約サービスの利用規約を遵守し、当該連携に必要な権限を自らの責任で確保するものとします。
  5. 契約者は、練習用の院に実在の患者情報を登録しないものとします。
  6. 契約者は、本サービスを利用するために必要な端末、通信回線その他の環境を自らの費用と責任で用意するものとします。

第10条（禁止事項）

契約者及び利用者は、本サービスの利用にあたり、次の各号に該当する行為をしてはなりません。

  1. 法令、公序良俗又は本規約に違反する行為
  2. 患者その他第三者の権利又は利益を侵害する行為
  3. 本サービスを、契約者が開設する院以外の医療機関又は第三者に利用させる行為（当社が書面により承諾した場合を除きます。）
  4. 本サービスの全部又は一部を複製、改変、翻案、逆コンパイル、逆アセンブル、リバースエンジニアリングする行為
  5. 本サービスに係るサーバ又はネットワークに過度な負荷をかける行為、不正アクセス又はこれを試みる行為
  6. 本サービスの脆弱性を探索する行為（当社が書面により承諾した場合を除きます。）
  7. 有害なプログラムを送信し、又は書き込む行為
  8. 他の利用者の認証情報を不正に使用する行為
  9. 本サービスを利用して競合するサービスを開発する目的で、本サービスの仕様、画面構成その他の情報を利用する行為
  10. その他当社が不適切と合理的に判断する行為

第11条（サービスの変更及び停止）

  1. 当社は、本サービスの機能の追加、変更又は廃止を行うことができます。ただし、契約者に重大な不利益を及ぼす変更又は廃止を行う場合は、合理的な期間を定めて事前に通知するものとします。
  2. 当社は、本サービスの保守、点検又は更新を行うため、本サービスの全部又は一部の提供を一時的に停止することができます。この場合、当社は、原則として7日前までに契約者に通知し、停止は可能な限り院の診療時間外に行うよう努めます。ただし、緊急を要する場合は、事後の通知とすることができます。
  3. 当社は、次の各号のいずれかに該当する場合、事前の通知なく本サービスの全部又は一部の提供を停止することができます。
    1. 天災地変、火災、停電、感染症の流行、戦争、暴動その他の不可抗力により本サービスの提供が困難となった場合
    2. 当社が利用するクラウド基盤、通信回線その他の外部サービスに障害又は停止が生じた場合
    3. 不正アクセス、サイバー攻撃その他のセキュリティ上の脅威に対処する必要がある場合
    4. その他当社が本サービスの提供の停止が必要と合理的に判断した場合
  4. 外部予約サービスの仕様変更、提供停止その他当社の支配の及ばない事由により連携機能の全部又は一部が利用できなくなった場合、当社は、合理的な範囲で代替手段の提供に努めますが、当該連携機能の継続を保証するものではありません。

第12条（障害時の対応及びサービス水準）

  1. 当社は、本サービスに障害が発生したことを知ったときは、速やかに契約者に通知し、復旧に努めます。
  2. 当社は、本サービスについて、月間稼働率99.5パーセント以上を目標として運用に努めます。ただし、当該目標は努力目標であり、当社はその達成を保証するものではなく、目標を達成しなかったことを理由として料金の減額、返金その他の責任を負うものではありません。
  3. 前項の稼働率の算定にあたっては、前条第2項及び第3項による停止の時間を除くものとします。
  4. 当社は、本サービスに保存された契約者データについて、覚書に定める方法によりバックアップを取得します。ただし、バックアップからの復元は、当社の合理的な判断により可能な範囲で行うものとし、すべての契約者データの完全な復元を保証するものではありません。
  5. 契約者は、障害時においても診療を継続できるよう、紙による記録その他の代替手段をあらかじめ用意するものとします。

第13条（免責及び責任の制限）

  1. 当社は、本サービスが契約者の特定の目的に適合すること、期待する機能、正確性及び有用性を有すること、並びに不具合が生じないことを保証するものではありません。
  2. 当社は、次の各号に起因して契約者に生じた損害について、責任を負いません。ただし、当社の故意又は重大な過失による場合はこの限りではありません。
    1. 第11条第3項各号に定める事由
    2. 外部予約サービスその他第三者が提供するサービスの内容、仕様変更、障害又は停止
    3. 契約者又は利用者の端末、通信環境又は認証情報の管理不備
    4. 契約者又は利用者による本規約違反
  3. 当社が本サービスに関して契約者に対して損害賠償責任を負う場合、その範囲は契約者に現実に生じた通常かつ直接の損害に限られるものとし、その額は、損害発生の原因となった事由が生じた日から遡って12か月の間に当社が契約者から現実に受領した料金の総額を上限とします。
  4. 前項の規定は、当社の故意又は重大な過失による場合には適用しません。

第14条（契約の解除）

  1. 当社及び契約者は、相手方が次の各号のいずれかに該当した場合、何らの催告を要せず、直ちに利用契約の全部又は一部を解除することができます。
    1. 本規約に違反し、相当の期間を定めて催告したにもかかわらず、当該期間内に是正しない場合
    2. 支払停止若しくは支払不能となり、又は破産手続開始、民事再生手続開始、会社更生手続開始若しくは特別清算開始の申立てがあった場合
    3. 差押え、仮差押え、仮処分又は競売の申立てを受けた場合
    4. 手形又は小切手が不渡りとなった場合
    5. 解散又は事業の全部若しくは重要な一部の譲渡の決議をした場合
    6. 次条の規定に違反した場合
  2. 当社は、契約者が料金の支払を2か月以上遅延した場合、何らの催告を要せず、利用契約を解除することができます。
  3. 前2項による解除は、解除した当事者による損害賠償の請求を妨げません。

第15条（反社会的勢力の排除）

  1. 当社及び契約者は、自ら又はその役員（業務を執行する社員、理事、取締役、執行役又はこれらに準ずる者をいいます。）若しくは実質的に経営を支配する者が、暴力団、暴力団員、暴力団員でなくなった時から5年を経過しない者、暴力団準構成員、暴力団関係企業、総会屋等、社会運動等標ぼうゴロ、特殊知能暴力集団その他これらに準ずる者（以下「反社会的勢力等」といいます。）に該当しないこと、及び次の各号のいずれにも該当しないことを表明し、将来にわたって保証します。
    1. 反社会的勢力等が経営を支配し、又は経営に実質的に関与していると認められる関係を有すること
    2. 自己若しくは第三者の不正の利益を図り、又は第三者に損害を加える目的をもって反社会的勢力等を利用していると認められる関係を有すること
    3. 反社会的勢力等に対して資金等を提供し、又は便宜を供与するなどの関与をしていると認められる関係を有すること
    4. 役員又は経営に実質的に関与している者が反社会的勢力等と社会的に非難されるべき関係を有すること
  2. 当社及び契約者は、自ら又は第三者を利用して、暴力的な要求行為、法的な責任を超えた不当な要求行為、取引に関して脅迫的な言動をし又は暴力を用いる行為、風説を流布し偽計を用い又は威力を用いて相手方の信用を毀損し又は業務を妨害する行為その他これらに準ずる行為を行わないことを確約します。
  3. 当社及び契約者は、相手方が前2項に違反した場合、何らの催告を要せず、直ちに利用契約を解除することができます。この場合、解除した当事者は、解除により相手方に生じた損害を賠償する責任を負いません。

第16条（知的財産権）

  1. 本サービスに関する著作権、特許権その他の知的財産権（本サービスのプログラム、画面構成、設計、文書及びこれらの改良物に係るものを含みます。）は、当社又は当社に利用を許諾した第三者に帰属します。
  2. 当社は、契約者に対し、利用契約の有効期間中、本サービスを院の業務の範囲内で利用する非独占的かつ譲渡不能な権利を許諾します。
  3. 契約者データに関する権利は、契約者又は正当な権利者に帰属し、当社は、本規約及び覚書に定める範囲を超えてこれを利用しません。
  4. 契約者が当社に対して本サービスに関する意見、要望又は改善提案を行った場合、当社はこれを無償で本サービスの改善に利用することができます。ただし、当該意見等に契約者データが含まれる場合、当該契約者データの取扱いは覚書の定めによります。

第17条（契約者データの取扱い）

  1. 当社は、契約者データを、本サービスの提供、保守、障害対応及び契約者からの問合せへの対応の目的の範囲内でのみ取り扱います。
  2. 患者情報の取扱いについては、覚書の定めによります。
